CEMETERY MANAGEMENT SOFTWARE | Help and Training

It's never been easier to learn cemetery software at your own pace

EverArk's help and training are embedded in the cemetery software so you and your team can implement and learn at your own pace. You can reference the Get Started wizard and videos to implement EverArk. And, to learn more about each feature, you can use the help checklists.

See how Help & Training works.
Get Started Wizard
Scroll through and complete the action items to setup EverArk.
By using the Get Started wizard in EverArk, you can scroll through the prioritized list of setup action items.  Going through the action list will help you implement and launch EverArk at your own pace.  You can check off each task as you do it to track your progress.
- EverArk Cemetery Software navigation:  My Workspace > Get Started link
Play Video Tutorials
Watch the Get Started action item videos to learn how to do them.
By watching each Get Started action item video, you will learn from an expert how to perform the setup task.  Each video tutorial will walk you through the navigation steps to perform the task.  By watching all the videos and performing all the tasks, EverArk will be ready to go.
​- EverArk Cemetery Software navigation:  My Workspace > Get Started link  | Get Started Video Series
Help Checklists
Use the Get Help checklist to learn about each cemetery software feature.
By selecting the Get Help link, you can learn about each feature.  The Get Help pages are available for all the menu views - Inventory, Sales, Customers, Invoices, and Maintenance.  Scroll through the prioritized list performing each task and checking them off as you go.
- EverArk Cemetery Software navigation:  Cemetery > Inventory, Sales, Customers, Invoices, and Maintenance > Get Help
Watch Quick Tip Series
Check out the Quick Tip video playlist to learn tips and tricks.
By watching the quick tip video series, you will get to learn from experts how to perform specific tasks and workflows.  These videos are created for our customers when they ask how to do something.  Our Quick Tip videos are a growing catalogue of use cases, so always check back to learn what other cemeteries are doing and asking.
- EverArk Cemetery Software navigation:  Quick Tip Video Series
Reference Tooltips
Hover over any of our tooltips to learn more about a field or calculation.

Frequently Asked Questions | Performance Dashboards

Can't find what you're looking for?  We would love to chat with you.
How often is data refreshed?
The cemetery, garden, and plot dashboards are refreshed in real-time.  That means, each time you click on the view, tab, or filter, the data and KPIs are refreshed.
Can I manage who has access to the dashboards?
Yes, each dashboard can be assigned to roles, or to specific users, so that navigational noise is minimized and managers can access only what they need to see.
What if I manage multiple cemeteries?
Not a problem. You can filter by cemetery in the overview such that all the dashboards and data are updated for the selected cemetery.
Can I request new metrics?
Yes, you can request custom metrics and performance indicators.  The default measures are a starting point and we are always looking to improve our dashboards so all cemeteries can operate more efficiently.
Can I export to Excel/CSV?
Yes, each dashboard has a set of tabs with a download option that allows you to export the visible data.
